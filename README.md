# 🧠 MekaMind - IoT Board Programming Platform

منصة برمجة لوحات IoT بصرياً - صمم، ولّد الكود، وارفع مباشرة عبر USB.

---

## 📦 تحميل وتشغيل المشروع

### المتطلبات الأساسية
- **Node.js** الإصدار 18 أو أحدث → [تحميل من هنا](https://nodejs.org/)
- **npm** (يأتي مع Node.js)

### خطوات التثبيت

```bash
# 1. انسخ ملفات المشروع لمجلد على جهازك
#    (حمّل الملفات من المنصة أو انسخها يدوياً)

# 2. افتح Terminal / Command Prompt في مجلد المشروع

# 3. ثبّت المكتبات المطلوبة
npm install

# 4. شغّل المشروع في وضع التطوير
npm run dev

# 5. افتح المتصفح على الرابط:
#    http://localhost:5173
```

### بناء المشروع للنشر (Production)

```bash
# بناء المشروع
npm run build

# الملفات الجاهزة للنشر ستكون في مجلد:
# dist/
```

| `/admin/dashboard` | لوحة تحكم الأدمن | **Admin فقط** |
| `/403` | صفحة ممنوع الدخول | عامة |

---

## 🛡️ نظام الحماية

### الفصل بين المنصتين:
1. **منصة المستخدم** (`/`) - متاحة للجميع، قراءة فقط للوحات
2. **لوحة الأدمن** (`/admin/*`) - محمية بـ JWT + RBAC

### آلية الحماية:
- **Route Guard** يتحقق من صلاحية `role: "admin"` قبل الدخول
- المستخدم العادي (`role: "user"`) يتم تحويله لصفحة 403
- لا توجد أي روابط في المنصة العامة تؤدي للأدمن
- الأدمن فقط يقدر يضيف/يعدل/يحذف اللوحات والـ Pin Mappings
